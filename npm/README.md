# cli-top

A command-line tool with a subcommand-based interface. Use the built-in help output to explore available commands and flags.

## Help

```bash
# Show top-level help
npx cli-top --help

# If installed globally or via a local bin
cli-top --help

# Show help for a specific subcommand
cli-top <subcommand> --help
```

## Common flags

```bash
cli-top --help
cli-top --version
cli-top --update
cli-top --debug
```
